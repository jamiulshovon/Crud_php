# PHP CRUD Application

A simple PHP CRUD (Create, Read, Update, Delete) application using **MySQL** and **Bootstrap 5**. This project demonstrates basic database operations with a web interface.

---

## Features

- **Create**: Add new client details.  
- **Read**: View a list of all clients in a table.  
- **Update**: Edit existing client information.  
- **Delete**: Remove client records.  
- **Bootstrap Alerts**: Success and error messages with close buttons.

---

## Technologies Used

- PHP (Procedural style with MySQLi)  
- MySQL / MariaDB  
- Bootstrap 5 for frontend styling  
- HTML & CSS
